# Kbd

Docs: https://docs.medusajs.com/ui/components/kbd
Import from `@medusajs/ui`. Installed kit is `4.2.1`.

A keyboard shortcut chip.

## When to open this file

Open this file when the view needs `Kbd`, or a related control from the index row for `kbd`.

## Usage

```tsx
<Kbd>Ctrl + Shift + A</Kbd>
```

## Kit props (`@medusajs/ui` 4.2.1)

This component is based on the `kbd` element and supports all of its props

## Official examples

### `kbd-demo.tsx`

```tsx
import { Kbd } from "@medusajs/ui";

export default function KbdDemo() {
  return <Kbd>⌘ + K</Kbd>;
}
```
