# Hint

This primitive is in `@medusajs/ui` 4.2.1. It may not have a dedicated docs.medusajs.com page.

Field help or error text under an input.

## When to open this file

Open this file when the view needs `Hint`.

## Kit props

- `variant`: `error` | `info`

## Atlas

Create and public auth field errors. `variant="error"` with `id="{inputId}-hint"`.

For a simple screen, follow the locked preview in `views.md`. Do not invent a new layout unless the human asks.
