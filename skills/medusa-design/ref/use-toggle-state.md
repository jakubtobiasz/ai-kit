Docs: https://docs.medusajs.com/ui/hooks/use-toggle-state

## When to open this file

Open this file when the view needs `useToggleState`.

## Usage

```tsx
const [state, open, close, toggle] = useToggleState();
```

## Atlas

Boolean open state helper. Previews use `useState` instead.
